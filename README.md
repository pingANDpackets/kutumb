# ☁️ Kutumb - Azure Cloud Cost Optimizer - Multi-Agent System

**Project for Microsoft Reactor Azure AI Hackathon** 🎯  
Built using: **Azure OpenAI**, **Azure Cost Management**, **Semantic Kernel**, and **Python**.

---

## 📚 Overview

Managing cloud costs is tricky!  
This project uses **AI agents** to **analyze**, **recommend**, and **simulate** optimizations for Azure resources based on cost usage.

✅ Uses live Azure billing and cost data  
✅ AI-powered cost analysis  
✅ Dummy simulation (no real Azure changes)  
✅ Safe to run on real subscriptions  
✅ Multi-agent framework with Semantic Kernel  

---

## 🧠 Architecture


Azure Cost Management ➡️ Azure OpenAI ➡️ Semantic Kernel ➡️ Cost Optimizer Agents ➡️ Command-Line Simulation
